# Scope after the full application implementation

The monthly India-first MVP is implemented, with the separate guest demo retained. Setup and verification steps are in the README and `operations.md`.

Live readiness depends on configuring Supabase/SMTP/OAuth, Gemini or OpenAI, and Cashfree sandbox credentials, running migration and browser acceptance checks, and publishing merchant disclosures. The environment cannot supply the operator’s legal/tax decisions or merchant approval.

PRD P1/P2 work remains outside the MVP: authorized Google review synchronization and replies, WhatsApp campaigns, international checkout, annual billing and proration, agency white-labeling, printed QR fulfillment, expanded languages and automated partial-refund service policies. None is represented by sample live data.
